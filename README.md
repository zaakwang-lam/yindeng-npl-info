# 银登中心个贷不良包信息工具

用微信开发者工具打开**这个文件夹**（里面直接有 `app.json`），不要打开上一级目录。

桌面上如果已经导入过旧版（只有一行标题、大片空白），用新文件覆盖那个目录，再点「编译」。

没有自己的小程序 AppID 时，选测试号即可预览。已有 AppID 的，在详情里改回自己的，不要用测试号上传。

打开后应看到深色抬头、「筛选」和每条上的「查看」。订阅按钮只弹说明，不会扣款。演示包上的金额是编的，不能拿去报价。
