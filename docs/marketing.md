# 获客文案

只发给同行。不要写能续、不要写内部底价。

## 微信群

做房抵和个贷包的同行，两个小工具在小范围试用，不发未核实的成交价。

1. 银登个人不良转让：先看公开标题和原文链接，PDF 里的未偿本息用脚本抽，抽不到就不报数字。
2. 续贷测算：填估值、剩余本金、房龄，按保守口径或几家广州常用行的经验抵押率，算出缺口。用来跟客户对齐预期，不是银行批复。

免费就能看标题。导出是付费档。要试用直接回我。

## 视频号口播（约 40 秒）

银登上的个人不良转让，公告是 PDF，翻一遍很慢。
我做了个标题流：只放公开标题和原文链接，未偿本息从 PDF 里抽，抽不到就空着。
不报起拍价，也不把演示数字当成交价。
做这行的同行，评论区留「标题」。
