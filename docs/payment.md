# 订阅支付

先用对公或视频号收到第一笔，再接小程序虚拟支付。

## 档位

| 档 | 价格 | 解锁 |
| --- | --- | --- |
| 免费 | 0 | 标题浏览 |
| 提醒 | 29 元/月 | 保存筛选，命中后的群发草稿 |
| 专业 | 69 元/月 | 导出 |
| 全功能 | 99 元/月 | 提醒 + 导出 |

道具 ID 见 `utils/pay.js`。金额单位是分。

## 接入顺序

1. 个人主体不能开虚拟支付。用企业主体小程序。类目按工具或资讯申报，金融类目审核更严，以微信当日规则为准。
2. mp 后台开通虚拟支付，把月卡配成道具。
3. 服务端用 session_key 算用户态签名，用虚拟支付 appKey 算 pay_sig。签名和 appKey 不进小程序包。
4. 前端拿服务端原样的 signData 调 `wx.requestVirtualPayment`。道具直购的 mode 以最新文档为准，目前骨架用 `short_series_goods`。
5. 是否到账以服务端支付通知为准，再给 openid 记到期日。前端 success 只能刷新界面。
6. iOS 虚拟商品限制会变。先保安卓能付。iOS 不行就改对公，不要引导绕过苹果。

不要卖保续、不要展示未公开的起拍价。
