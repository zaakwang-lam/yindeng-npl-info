# 产品需求文档 (PRD) - 银登中心个贷不良包信息工具

## 1. 背景与目标
个贷不良批量转让活跃，银登中心公开公告为PDF格式，同行手动提取效率低。目标：提供便捷的信息聚合、筛选、提醒工具。

## 2. 目标用户
不良资产同行、代理人员、小AMC、处置团队、投资人。

## 3. 核心功能点
- 最新挂牌列表（分页、下拉刷新）
- 详情页：自动提取关键字段
- 多维筛选：地区（广东/广州等）、资产类型（信用卡透支/消费贷/经营贷）、账龄区间、未偿本息规模
- 关键词搜索
- 订阅提醒（按地区/类型，付费）
- 数据导出（Excel/CSV，付费）
- 历史数据查询（付费）

## 4. 页面流程
1. 首页（列表）：展示最新挂牌，点击进入详情
2. 筛选页：多条件筛选后返回列表
3. 详情页：字段表格 + 原始PDF链接
4. 我的：订阅管理、导出记录、付费入口

## 5. 数据字段（从PDF提取）
- 项目名称、出让方、交易基准日
- 资产笔数、借款人数
- 未偿本金总额、未偿利息总额、未偿本息总额
- 加权平均逾期天数
- 五级分类分布（次级/可疑/损失）
- 担保情况、诉讼情况
- 地区（从公告推断）

## 6. 数据获取方案
- 定时任务（云函数/本地脚本）访问银登网转让公告列表页
- 下载PDF，使用 pdfplumber 提取字段（参考已有GitHub代码）
- 结果存入数据库（云开发数据库或自建）
- 小程序调用后端API获取结构化数据
- 备注：遵守网站访问频率，仅公开信息

## 7. 变现方式
- 免费：最近列表、基础详情
- 付费订阅（虚拟支付）：提醒、高级筛选、导出、历史数据（29/69/99元/月）
- 赞赏组件作为补充

## 8. 非功能需求
- 响应速度快
- 数据准确性（提取规则可调优）
- 隐私：不收集用户敏感信息
